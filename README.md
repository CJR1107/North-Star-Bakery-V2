# North Star Bakery

This is a four-page website I made for North Star Bakery. I wanted people to be able to see what the bakery sells, learn a little about it, and find the information they need to ask about an order.

## What's on the website

- **Home:** A welcome section, featured bread, bakery hours, and a short audio message.
- **Our Menu:** Breads, pastries, and cakes with descriptions and price ranges.
- **Our Story:** Some background on the bakery, where ingredients come from, and the people who work there.
- **Contact:** Hours, location details, and a form for pre-orders or general questions.

## How I built it

I used HTML for the four pages, CSS for the styling, and a separate JavaScript file for the interactive parts. I went with dark green, cream, sage, and gold because I thought they worked well for a small bakery. I also used Flexbox and a media query so the pages are easier to use on both phones and larger screens. The images and welcome audio are saved in the `assets` folder.

## Opening the site

Open `index.html` in a web browser. All the pages link to each other, and no extra software is needed.

The menu lets visitors save favorite items in their browser. The contact form gives messages for missing or incorrect entries and remembers the selected request type. The form does not send real orders. The business address, hours, and prices are examples for the website.
